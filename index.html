07 FAQ

คำถามที่ควรถาม
ก่อนเริ่ม.

ถ้าคำถามของคุณยังไม่มีในนี้ ส่งมาถามเราได้เลย เราตอบตรง ๆ แม้คำตอบจะเป็น “ยังไม่ควรทำ”

ถามคำถามอื่น

ธุรกิจ B2B ที่มีทีมตั้งแต่ประมาณ 20 คนขึ้นไป มีกระบวนการที่ต้องรอคน รอข้อมูล หรือทำงานซ้ำหลายชั่วโมงต่อสัปดาห์ และมีระบบดิจิทัลพื้นฐานอยู่แล้ว เช่น CRM, Google Workspace, LINE OA หรือ ERP. เราเริ่มจากการหา bottleneck ก่อน แล้วค่อยเลือกว่าจะ automate จุดไหน

โดยปกติไม่ต้อง. เราออกแบบให้ระบบที่ deploy บน Modal.com เชื่อมกับเครื่องมือที่ทีมใช้อยู่ผ่าน API หรือ automation layer. หากจำเป็นต้องเปลี่ยน จะต้องมีเหตุผลชัดเจนด้านต้นทุน ความเสี่ยง หรือข้อจำกัดทางเทคนิค และเราจะแสดงทางเลือกให้เห็นก่อนตัดสินใจ

หลังคุยและเลือกคอขวด ระบบแรกมักใช้เวลา 3–6 สัปดาห์สำหรับการสร้างและ deploy บน Modal.com และเริ่มเห็นตัวเลขจริงภายใน 30–60 วันหลังใช้งาน. เราส่งงานเป็น sprint พร้อม demo ให้ตรวจทุกสัปดาห์ และมีช่วง aftercare ดูแลต่อหลัง launch

เราเริ่มจากการประเมิน data flow และความอ่อนไหวของข้อมูลก่อนเลือกเครื่องมือ. แนวทางที่ใช้ได้แก่ การจำกัดสิทธิ์ตามบทบาท, การใช้ enterprise endpoints ที่ไม่นำข้อมูลไป train, การเก็บ log, จุดอนุมัติโดยมนุษย์ และการใช้ secrets management ของ Modal.com แยก credential ออกจาก code. ขอบเขตด้านข้อมูลจะระบุไว้ในสัญญาก่อนเริ่มงาน
